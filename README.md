# 財務分析儀表板 · finance

個人收支與副業損益的互動式分析儀表板集合。全部為**單一自包含 HTML 檔**，下載後用瀏覽器直接打開即可，不需要架伺服器或安裝任何東西。

---

## 快速開始

打開 `index.html`，左側選單可切換兩份儀表板。

若已開啟 GitHub Pages，網址為：
`https://milulee-tw.github.io/finance/`

## 計算口徑（重要）

儀表板的數字經過以下歸屬規則處理，與 App 內的原始加總不會完全一致：

- 已排除**轉帳、信用卡繳款**等非實際收支
- 2017 年含房貸一次性支付（約 1,078 萬），於**歷年比較圖表中排除**，避免壓縮其他年度的視覺比例
- **藍玥資訊**費用視為公司開銷，不列入個人支出
- **米鹿私藏**獨立計算損益（進貨、運費、廣告費等歸為其支出）
- **部門經費／公司代墊**屬任職公司往來款，非個人消費性支出
- 非 TWD 消費依**年度平均匯率**換算後併入個人收支。收支儀表板 v4 起，換算在**頁面內即時執行**：匯率表 `FX_RATES` 位於 `<script>` 最上方，改完存檔重新整理，全站數字會跟著變
- 米鹿私藏 v5 起，非 TWD **進貨**亦納入該儀表板統計（兩份儀表板共用同一套匯率）；累積淨利因此由 +281,526 修正為 +96,364

### 已知限制

- 米鹿私藏 v5 起，成本對應改以「貨號 → 品項或實際名稱 → 類別估算」三層比對，精算涵蓋率由 13.4% 提升至 **77.5%**；剩餘 22.5% 仍為類別平均估算，該部分毛利僅適合看相對高低
- 部分客製報價連結單價設為 $1、買家以「買 N 件」湊金額，導致**件數欄虛胖**（銷售額與毛利不受影響）
- 2021/12 – 2023/05 開店初期無訂單明細，該期間僅能由 AndroMoney 回看

## 技術規格

- 單一自包含 HTML，無建置流程
- 圖表：Chart.js 4.4.1（cdnjs CDN，需連網才能顯示圖表）
- 深色主題；字體 `-apple-system` / `PingFang TC`
- `index.html` 以 iframe 載入各儀表板，切換時重新載入以確保圖表寬度正確

## 更新方式

1. 由 AndroMoney 匯出最新資料
2. 在本機專案資料夾以產生器重算儀表板（收支）／執行對應 skill（米鹿私藏）
3. 將新版 HTML 覆蓋本 repo 對應檔案後 commit

最後更新：2026/08/30（收支儀表板 v4、米鹿私藏 v5，資料皆至 2026/08/27）

版本沿革與詳細決策紀錄留在本機專案資料夾的 `WORKLOG.md` / `DECISIONS.md`，未納入本 repo。
